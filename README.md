# MC&O Cleaning Operations

Build an existing-project-style, professional web application prototype called **MC&O Cleaning Operations**.

This is a portfolio concept demonstrating a cleaning management platform for a cleaning company with approximately 15 employees, 12 customers and 15 cleaning locations.

IMPORTANT:
- Build a functional prototype, not a production-ready enterprise SaaS.
- Use React, TypeScript and the existing Lovable-supported stack.
- Do not introduce PHP or claim PHP implementation.
- Use a clean, restrained, premium business-software design.
- Avoid gradients, glassmorphism, glowing effects, excessive animations, oversized rounded cards and AI-looking visual styling.
- Use a light background, dark readable typography, subtle borders and restrained accent colours.
- Make the entire interface responsive across desktop, tablet and mobile.

APPLICATION STRUCTURE:

Create a professional dashboard shell with:
- Left sidebar navigation on desktop.
- Collapsible/mobile navigation on smaller screens.
- Top bar with page title, search area, notifications and profile menu.
- Consistent content spacing and reusable components.

Navigation:
1. Dashboard
2. Customers
3. Locations
4. Employees
5. Schedule
6. Attendance
7. Financial Overview
8. Settings

DASHBOARD:
Display summary metrics for:
- Active customers
- Active employees
- Cleaning locations
- Today's scheduled shifts

Include:
- Today's schedule
- Upcoming cleaning assignments
- Recent activity
- Operational overview

Use realistic fictional data. Do not use real people's personal information.

Create the navigation, page layouts and visual foundations first. Each navigation item should open its own page, even if some pages initially contain placeholder content.

Use clear page headings, accessible labels, visible keyboard focus states and consistent buttons.

Do not build authentication, payments, accounting integrations, GPS tracking, complex scheduling automation or multi-tenant infrastructure yet.

The result should look like a credible professional cleaning operations application, not a generic admin dashboard.
